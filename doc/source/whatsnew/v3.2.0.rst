I/O
^^^
- Fixed bug in :func:`read_csv` where passing a ``dtype`` dict with integer keys that are out of range as positional column indices (e.g. all-negative keys like ``{-10: "float64"}``) raised ``IndexError`` instead of treating the keys as column names (:issue:`57944`)
