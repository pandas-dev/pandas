Increased minimum versions for dependencies
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
Some minimum supported versions of dependencies were updated.
If installed, we now require:

+-----------------+-----------------+----------+---------+
| Package         | Minimum Version | Required | Changed |
+=================+=================+==========+=========+
|                 |                 |    X     |    X    |
+-----------------+-----------------+----------+---------+

For `optional libraries <https://pandas.pydata.org/docs/getting_started/install.html>`_ the general recommendation is to use the latest version.
The following table lists the lowest version per library that is currently being tested throughout the development of pandas.
Optional libraries below the lowest tested version may still work, but are not considered supported.

+-----------------+-----------------+---------+
| Package         | Minimum Version | Changed |
+=================+=================+=========+
|                 |                 |    X    |
+-----------------+-----------------+---------+

See :ref:`install.dependencies` and :ref:`install.optional_dependencies` for more.

I/O
^^^
- :func:`read_json` with ``orient="table"`` now reads back non-string column labels and index names, such as the default integer columns of ``DataFrame([[1, 2]])``, instead of returning all-NaN values or raising ``IntCastingNaNError``; labels that cannot be matched to their data, such as ``5`` and ``"5"`` in the same frame, now raise ``ValueError`` (:issue:`19129`)
- :meth:`DataFrame.to_json` and :meth:`Series.to_json` with ``orient="table"``, and :func:`build_table_schema`, no longer raise ``AttributeError`` for a :class:`MultiIndex` with non-string level names (:issue:`19129`)
- :meth:`Series.to_json` with ``orient="table"`` no longer writes a falsy :class:`Series` name such as ``0``, ``False`` or ``""`` as the placeholder ``"values"``; only an unnamed :class:`Series` gets the placeholder (:issue:`19129`)
