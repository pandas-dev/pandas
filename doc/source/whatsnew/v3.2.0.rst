Notable bug fixes
~~~~~~~~~~~~~~~~~

These are bug fixes that might have notable behavior changes.

.. _whatsnew_320.notable_bug_fixes.partial_string_no_matches:

Partial string indexing that matches no entries raises ``KeyError``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Indexing a :class:`DatetimeIndex` or :class:`PeriodIndex` with a partial string
that matched none of its entries sometimes returned an empty result instead of
raising ``KeyError``:

.. code-block:: ipython

    In [1]: dti = pd.to_datetime(["2024-02-24 10:00:30", "2024-02-24 10:20:30"])

    In [2]: ser = pd.Series([1, 2], index=dti)

    In [3]: ser["2024-02-24 10:08"]
    Out[3]: Series([], dtype: int64)

Such a key now raises ``KeyError`` in every case, including on an empty index.
Consequently ``"2024-02-24 10:08" in dti`` is now ``False``, assigning to such a
label with :meth:`Series.loc` or :meth:`DataFrame.loc` adds it to the object
instead of silently discarding the assignment, and a :class:`MultiIndex` slice
bounded by such a string no longer selects entries past the bound
(:issue:`57596`). To get an empty result instead of raising, use a slice, e.g.
``ser["2024-02-24 10:08":"2024-02-24 10:08"]``.

.. _whatsnew_320.api_breaking.deps:

Increased minimum versions for dependencies
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
Some minimum supported versions of dependencies were updated.
If installed, we now require:

+-----------------+-----------------+----------+---------+
| Package         | Minimum Version | Required | Changed |
+=================+=================+==========+=========+
|                 |                 |    X     |    X    |
+-----------------+-----------------+----------+---------+

For `optional libraries <https://pandas.pydata.org/docs/getting_started/install.html>`_ the general recommendation is to use the latest version.
The following table lists the lowest version per library that is currently being tested throughout the development of pandas.
Optional libraries below the lowest tested version may still work, but are not considered supported.

+-----------------+-----------------+---------+
| Package         | Minimum Version | Changed |
+=================+=================+=========+
|                 |                 |    X    |
+-----------------+-----------------+---------+

See :ref:`install.dependencies` and :ref:`install.optional_dependencies` for more.
